# 第02章 算法分析 — 练习题与答案提示

1) 循环复杂度
```
 x = 0;
 while ( n >= (x+1)*(x+1) ) x = x+1;
```
问：循环次数与时间复杂度是多少？
- 答：Θ(√n)。理由：循环条件 (x+1)^2 ≤ n ⇒ x ≈ √n。

2) 递推方程（主定理）
P1: T(1)=1, T(N)=T(N/3)+1；P2: T(1)=1, T(N)=3T(N/3)+1。
问：分别求解渐进复杂度。
- 答：P1 Θ(log N)，P2 Θ(N)。理由见主定理或递归树展开。

3) 复杂度比较
判定以下函数增长关系：n log n, n^2, 2^n。
- 答：n log n < n^2 << 2^n。

4) 递归树应用
T(n)=2T(n/2)+n，求 T(n)。
- 答：Θ(n log n)。递归树每层工作量为 n，共 log n 层。

5) 算法常数估算（应用）
若算法 A 为 O(n) 且在 n=100 时耗时 100s；算法 B 为 O(n^2) 且在 n=100 时耗时 30s。估计当 n=200 时哪算法更快？
- 答：估常数后比较 c·g(n)。示例：A: c=1 → 200；B: c=30/10000=0.003 → 0.003*40000=120 → B 更快。

6) 递归空间与迭代
朴素递归 Fibonacci 的时间与空间复杂度分别是多少？如何将空间降至 O(1)？
- 答：时间指数（O(2^n)），空间 O(n)（递归深度）。用迭代或动态规划可把空间降到 O(1)（滚动变量）。
