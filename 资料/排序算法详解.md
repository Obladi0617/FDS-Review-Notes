# 排序算法详解（覆盖试题中涉及的算法）

本文针对你题目中出现并容易出错的排序算法做系统讲解：算法思想、伪代码/步骤、时间/空间复杂度、稳定性、数组/链表适用性、常见易错点与小例子。

涵盖算法：冒泡、插入、选择、希尔（Shell）、归并、快速、堆、基数（LSD）等。

---

## 一、常用复杂度符号速览
- 平均/最坏/最好时间复杂度用 $O(),\Theta(),\Omega()$ 表示。
- 常见：$O(n^2)$、$O(n\log n)$、$O(n)$。

---

## 二、冒泡排序（Bubble Sort）
- 思想：重复遍历数组，比较相邻两元素并在必要时交换，使最大（或最小）元素逐步“冒泡”到一端。
- 伪代码（降序版本）：
  - for i = 1 to n-1:
    - for j = 1 to n-i:
      - if A[j] > A[j+1] then swap(A[j], A[j+1])
- 时间复杂度：最好 $O(n)$（已排好时可提前终止），平均/最坏 $O(n^2)$。
- 空间：$O(1)$（就地）。
- 稳定：是（相等元素相对次序不变）。
- 数组/链表：在数组上实现简单；链表实现可用常数次指针操作交换邻接节点，但指针操作常数较大。
- 易错点：误以为在任意情况下都能提前确定全部元素就位；注意需要外层循环条件或标志变量优化。

示例（数组 [5,1,4,2] 的一次完整排序过程）：
- 第1趟： [5,1,4,2] → [1,5,4,2] → [1,4,5,2] → [1,4,2,5]
- 第2趟： [1,4,2,5] → [1,2,4,5]（随后已有序，可提前结束）

---

## 三、插入排序（Insertion Sort）
- 思想：把数组分成已排序前缀和待插入后缀，每次把待插元素插入已排序段的正确位置。
- 伪代码：
  - for i = 2 to n:
    - key = A[i]; j = i-1
    - while j >=1 and A[j] > key: A[j+1]=A[j]; j--
    - A[j+1]=key
- 时间复杂度：最好 $O(n)$（已近似有序），平均/最坏 $O(n^2)$。当逆序对很少时非常快。
- 空间：$O(1)$。
- 稳定：是。
- 数组/链表：在数组中插入需要搬移元素；链表可以在已定位节点后常数时间插入，但定位位置仍需线性搜索，因此总体仍多为 $O(n^2)$，但若插入位置接近当前则链表优势明显。
- 考点：当数组的逆序数很小（如题中“若逆序数小于 20”）时，插入排序往往优于快速排序/堆排序。

---

## 四、选择排序（Selection Sort）
- 思想：每一趟从未排序区选择最小（或最大）元素，放到已排区末尾。
- 伪代码：
  - for i = 1 to n-1:
    - min = i
    - for j = i+1 to n: if A[j] < A[min] then min=j
    - swap(A[i], A[min])
- 时间复杂度：始终 $O(n^2)$（比较次数固定）。
- 空间：$O(1)$。
- 稳定：通常为不稳定（可通过额外移动实现稳定，但需额外开销）。
- 链表：可以通过摘取最小结点后接到已排表尾实现，但查找最小仍需遍历。

---

## 五、希尔排序（Shell Sort）
- 思想：分组插入——按若干增量(gap)把序列分成若干子序列，分别进行插入排序，最后 gap=1 完成一次插入排序。
- 关键：增量序列（gap）决定性能；常用序列有 Shell 原始 (n/2, n/4, ...)、Knuth (1,4,13,40,...), Sedgewick 等。
- 复杂度：依 gap 序列而异；常见均摊在 $O(n^{1.25})$ 到 $O(n^{1.5})$ 或更差；不保证 $O(n\log n)$。最终 gap=1 时退化为插入排序。
- 空间：$O(1)$。
- 稳定：否（因为同一子序列插入可能改变等值元素顺序）。
- 链表 vs 数组：**非常依赖随机访问**（需要跳跃访问 i+gap）。在链表上实现会因为跳步需要顺序遍历而变得非常慢；因此题目中判定 Shell 在链表上变慢正确（题 34）。

示例：用 gap=3,1 对数组做两次 run（可对应试题中观测到的中间结果）。

---

## 六、归并排序（Merge Sort）
- 思想：分治。把序列递归拆为左右两半，分别排序再合并。
- 伪代码（递归）：
  - if n<=1 return
  - mid = n/2; sort(left); sort(right); merge(left,right)
- 时间复杂度：最好/平均/最坏均为 $O(n\log n)$。
- 空间：通常需要 $O(n)$ 额外空间用于合并；链表合并可原地用指针，空间 $O(1)$。
- 稳定：是（按合并方法实现时）。
- 链表优势：对链表非常友好（中间拆分与合并可用指针，不需要额外数组）。

---

## 七、快速排序（Quicksort）
- 思想：分治。选枢轴(pivot)，把数组划分为小于枢轴、等于、和大于枢轴三部分，递归排序两边。
- 关键在 partition 的实现（Lomuto、Hoare、双指针变体）。
- 平均时间复杂度：$O(n\log n)$；最坏：$O(n^2)$（如每次枢轴为最小或最大）。
- 空间：递归栈平均 $O(\log n)$，最坏 $O(n)$（可用尾递归优化）。
- 稳定性：原地实现通常不稳定。
- 均衡与枢轴选择：采用随机化或三数取中可避免最坏情况。
- **等值键的处理（考试常考点）**：
  - 若 partition 实现不当（比如一侧指针在遇到等于 pivot 时会停，而另一侧遇到等于则继续），当数组中大量相同键时，partition 可能不能把等值元素适当分散，会导致递归退化为 $O(n^2)$（对应试题 38/39 的考点）。
  - 解决方法：三路划分（Dutch National Flag）把 <pivot、=pivot、>pivot 三类一次划分，可在存在大量重复键时实现近 $O(n)$ 的划分，从而总复杂度稳定为 $O(n\log n)$。

示例（三路划分思路）：
- 维护 lt, i, gt 指针；遍历 i，当 A[i]<pivot swap(A[lt++],A[i++])；A[i]>pivot swap(A[i],A[gt--])；A[i]==pivot i++。

---

## 八、堆排序（Heapsort）
- 思想：把数组视为二叉堆（通常构造最大堆），反复把堆顶（最大）放到数组末端并缩小堆。
- 关键操作：建堆（build-heap）、下滤（sift-down）和 DeleteMax。
- 建堆有两种常见方法：
  - 逐个插入（n 次上滤）：$O(n\log n)$。
  - Floyd 的线性建堆（从 ⌊n/2⌋ 向下对每个节点做下滤）：$O(n)$。这是考试常考点（不要把建堆误认为需 $O(n\log n)$）。
- 总体排序复杂度：$O(n\log n)$。
- 空间：$O(1)$（就地）。
- 稳定性：非稳定。
- 数组/链表：堆依赖节点的索引计算（parent=i/2, child=2i,2i+1），链表上无法常数时间实现这些索引操作，因此链表实现堆排序非常低效→题 34 中堆排序变慢。

建堆示例（题中示例）：给定层序 [1,3,2,5,4,7,6]，按 i=3→2→1 下滤得到最大堆 [7,5,6,3,4,2,1]（可逐步写出交换过程）。

---

## 九、基数排序（Radix Sort，LSD）
- 思想：按位分配排序（低位优先 LSD 或 高位优先 MSD），每位使用稳定的排序（如计数排序或队列桶）处理。
- 复杂度：若有 d 位且基数为 b，复杂度 $O(d(n+b))$。对定长整数或短字符串很高效。
- 空间：需额外桶/队列空间。
- 稳定：依赖于每位采用的稳定排序，整体为稳定。
- **LSD 示例（对应试题）**：
  - 给序列：321,156,57,46,28,7,331,33,34,63。按最低位（个位）分桶 0..9，依次把每个数字按原序放入对应桶，最后按桶序 concatenate 得到：
    - bucket1: 321,331
    - bucket3: 33,63
    - bucket4: 34
    - bucket6: 156,46
    - bucket7: 57,7
    - bucket8: 28
    - 其它桶空
    - 结果（首轮）：`321,331,33,63,34,156,46,57,7,28`（对应试题选项 B）

## 十、算法对数据结构（数组 vs 链表）的适配建议
- 需要随机下标访问或父/子索引的算法（希尔、堆）**强烈依赖数组**，在链表上效率低。题 34 正好考查此点。
- 归并排序在链表上非常适合（合并时只改指针，无额外数组）。
- 插入排序在链表上便于插入操作，但仍需线性查找插入位置；若数据近似有序，插入排序很快。
- 快速排序在链表上实现比较麻烦（分割步需频繁重连），通常不作为链表首选。

---

## 十一、稳定性与空间/时间综合比较表（速览）
- 冒泡：$O(n^2)$，$O(1)$，稳定
- 插入：$O(n^2)$（最好 $O(n)$），$O(1)$，稳定
- 选择：$O(n^2)$，$O(1)$，不稳定
- 希尔：依 gap，通常优于插入，小空间，不稳定
- 归并：$O(n\log n)$，$O(n)$（链表可$O(1)$），稳定
- 快速：平均 $O(n\log n)$，最坏 $O(n^2)$，$O(\log n)$ 递归栈，通常不稳定
- 堆：$O(n\log n)$，$O(1)$，不稳定
- 基数（LSD）：$O(d(n+b))$，额外桶空间，稳定

---

## 十二、考试常见考点与答题技巧
- “线性建堆”是重点：从 ⌊n/2⌋ 向下下滤可 $O(n)$ 建堆。不要把建堆误认为必须 $n$ 次插入。
- 快排的 partition 实现细节会影响同键分布性能，遇大量相同键要想到三路划分。
- 判断算法在链表上性能变化时，关注是否需要随机下标访问或父/子索引（希尔、堆）即可断定会变慢。
- 基数排序每一位必须稳定；做 LSD 时每一轮保持输入相对先后顺序。
- 插入排序在逆序对少时优势明显，逆序对数常直接决定插入排序常数因子表现。

### 1) 线性建堆（Floyd）——逐步打印中间状态（Python, 0-based）
```python
def sift_down(A, start, end):
  root = start
  while True:
    child = 2*root + 1
    if child > end:
      break
    # 选较大子
    if child+1 <= end and A[child] < A[child+1]:
      child += 1
    if A[root] < A[child]:
      A[root], A[child] = A[child], A[root]
      root = child
    else:
      break

def build_max_heap(A):
  n = len(A)
  # 从最后一个非叶子节点开始
  for start in range((n-2)//2, -1, -1):
    sift_down(A, start, n-1)
    print(f'after sift start={start}, A={A}')

# 演示
A = [1,3,2,5,4,7,6]
print('initial', A)
build_max_heap(A)
print('final heap', A)
```

运行说明：每次下滤后打印数组，便于观察 `i` 从 `floor(n/2)` 到 `1` 的中间状态，直接对应考试中逐步下滤的过程。

### 2) 快速排序三路划分（三色 Dutch Flag）伪代码与要点
伪代码（处理大量等值元素时推荐）：
```
quicksort3(A, lo, hi):
  if lo >= hi: return
  pivot = A[lo]
  lt = lo       # A[lo..lt-1] < pivot
  i = lo + 1    # A[lt..i-1] == pivot
  gt = hi       # A[gt+1..hi] > pivot
  while i <= gt:
    if A[i] < pivot:
      swap(A[lt], A[i]); lt += 1; i += 1
    elif A[i] > pivot:
      swap(A[i], A[gt]); gt -= 1
    else:
      i += 1
  quicksort3(A, lo, lt-1)
  quicksort3(A, gt+1, hi)
```
要点：此方法把等值键聚为一块，避免了大量相等键时的递归退化（考试题 38/39 的核心考点）。

示例：A=[5,3,5,8,5,1]，pivot=5，划分后得到 <5 =5 >5 三段，例如 [3,1 | 5,5,5 | 8]。

### 4) 希尔排序示例（gap 序列与局部插入）
示例数组： `[8,3,9,11,2,1,4,7,5,10,6]`。
设 gap 序列为 [3,1]（两次 run）：
- gap=3 时，把序列分为 3 个子序列，分别执行插入排序（下标差为 3 的元素归为一组），得到第一跑结果（示例题可能给出的中间结果）。
- gap=1 最终退化为普通插入排序，完成最终有序。

注意：在链表上实现 gap 跳跃访问代价高（每次跳步需线性遍历），故希尔排序在链表上性能差。

### 5) 堆建堆的逐步索引说明（对应题 8 精确索引）
1-based 索引与数值初始状态：

index: 1  2  3  4  5  6  7
value: 1  3  2  5  4  7  6

- i=3（节点值 2）：左右子为索引 6 (7) 和 7 (6)，较大为子 6（值 7），交换位置 3 与 6 → 1 3 7 5 4 2 6
- i=2（节点值 3）：左右子为索引 4 (5) 和 5 (4)，较大为 4（5），交换 2 与 4 → 1 5 7 3 4 2 6
- i=1（节点值 1）：左右子 2 (5)，3 (7)，较大为 3（7），交换 1 与 3 → 7 5 1 3 4 2 6；随后对位置 3 下滤，子 6 (2) 与 7 (6)，较大为 7（6），交换 → 7 5 6 3 4 2 1

最终得到最大堆：`[7,5,6,3,4,2,1]`（与题中答案一致）。

## C 语言实现示例
下面给出各排序算法的精简 C 语言实现（教学用途），都使用 0-based 数组索引并保证易读性。复制到 `.c` 文件后可用 `gcc -O2` 编译测试。

### 冒泡排序（Bubble Sort）
```c
void bubble_sort(int A[], int n) {
  int i, j, tmp;
  for (i = 0; i < n - 1; ++i) {
    int swapped = 0;
    for (j = 0; j < n - 1 - i; ++j) {
      if (A[j] > A[j+1]) {
        tmp = A[j]; A[j] = A[j+1]; A[j+1] = tmp;
        swapped = 1;
      }
    }
    if (!swapped) break;
  }
}
```

### 插入排序（Insertion Sort）
```c
void insertion_sort(int A[], int n) {
  int i, j, key;
  for (i = 1; i < n; ++i) {
    key = A[i];
    j = i - 1;
    while (j >= 0 && A[j] > key) {
      A[j+1] = A[j];
      --j;
    }
    A[j+1] = key;
  }
}
```

### 选择排序（Selection Sort）
```c
void selection_sort(int A[], int n) {
  int i, j, min_idx, tmp;
  for (i = 0; i < n - 1; ++i) {
    min_idx = i;
    for (j = i + 1; j < n; ++j) if (A[j] < A[min_idx]) min_idx = j;
    if (min_idx != i) {
      tmp = A[i]; A[i] = A[min_idx]; A[min_idx] = tmp;
    }
  }
}
```

### 希尔排序（Shell Sort）
```c
void shell_sort(int A[], int n) {
  int gap, i, j, temp;
  for (gap = n/2; gap > 0; gap /= 2) {
    for (i = gap; i < n; ++i) {
      temp = A[i];
      for (j = i; j >= gap && A[j-gap] > temp; j -= gap) A[j] = A[j-gap];
      A[j] = temp;
    }
  }
}
```

### 归并排序（Merge Sort）
```c
#include <stdlib.h>
void merge(int A[], int tmp[], int l, int m, int r) {
  int i = l, j = m+1, k = l;
  while (i <= m && j <= r) tmp[k++] = (A[i] <= A[j]) ? A[i++] : A[j++];
  while (i <= m) tmp[k++] = A[i++];
  while (j <= r) tmp[k++] = A[j++];
  for (i = l; i <= r; ++i) A[i] = tmp[i];
}
void merge_sort_rec(int A[], int tmp[], int l, int r) {
  if (l >= r) return;
  int m = (l + r) >> 1;
  merge_sort_rec(A, tmp, l, m);
  merge_sort_rec(A, tmp, m+1, r);
  merge(A, tmp, l, m, r);
}
void merge_sort(int A[], int n) {
  int *tmp = (int*)malloc(n * sizeof(int));
  if (!tmp) return; /* 内存检查 */
  merge_sort_rec(A, tmp, 0, n-1);
  free(tmp);
}
```

### 三路快速排序（Dutch National Flag）
```c
static inline void swap_int(int *a, int *b) { int t = *a; *a = *b; *b = t; }
void quicksort3(int A[], int lo, int hi) {
  if (lo >= hi) return;
  int lt = lo, i = lo + 1, gt = hi;
  int pivot = A[lo];
  while (i <= gt) {
    if (A[i] < pivot) { swap_int(&A[lt++], &A[i++]); }
    else if (A[i] > pivot) { swap_int(&A[i], &A[gt--]); }
    else { ++i; }
  }
  quicksort3(A, lo, lt-1);
  quicksort3(A, gt+1, hi);
}
```

### 堆排序（Heapsort）
```c
static void sift_down(int A[], int n, int i) {
  int largest = i;
  for (;;) {
    int l = 2*i + 1, r = 2*i + 2;
    if (l < n && A[l] > A[largest]) largest = l;
    if (r < n && A[r] > A[largest]) largest = r;
    if (largest != i) { int t=A[i]; A[i]=A[largest]; A[largest]=t; i = largest; }
    else break;
  }
}
void heap_sort(int A[], int n) {
  for (int i = n/2 - 1; i >= 0; --i) sift_down(A, n, i);
  for (int i = n - 1; i > 0; --i) {
    int t = A[0]; A[0] = A[i]; A[i] = t;
    sift_down(A, i, 0);
  }
}
```

### LSD 基数排序（非负整数）
```c
#include <stdlib.h>
void radix_lsd(int A[], int n) {
  if (n <= 0) return;
  int i, exp = 1, max = A[0];
  for (i = 1; i < n; ++i) if (A[i] > max) max = A[i];
  int *tmp = (int*)malloc(n * sizeof(int));
  int count[10];
  while (max / exp > 0) {
    for (i = 0; i < 10; ++i) count[i] = 0;
    for (i = 0; i < n; ++i) count[(A[i] / exp) % 10]++;
    for (i = 1; i < 10; ++i) count[i] += count[i-1];
    for (i = n-1; i >= 0; --i) tmp[--count[(A[i]/exp)%10]] = A[i];
    for (i = 0; i < n; ++i) A[i] = tmp[i];
    exp *= 10;
  }
  free(tmp);
}
```
